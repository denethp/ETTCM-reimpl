ETTCM re-implementation: all commands
=======================================

Every command below is run from the reimpl/ folder with the virtual environment active.
Times are on our laptop. The first run of a script pauses for a few seconds while Numba
compiles the estimator; that is normal.

WARNING: --csv APPENDS rows to a results file. Leave it out for demos, or you get
duplicate rows. Figure commands with --out ../figures/... OVERWRITE the saved figures;
for a demo write to another folder (e.g. ../demo_out/, created automatically).


0. SET-UP
---------
Every time you open a terminal:

    cd ~/ettcm-project/ETTCM-reimpl/reimpl
    source .venv/bin/activate

First time only, on a new machine:

    python3 -m venv .venv
    source .venv/bin/activate
    pip install -r requirements.txt

Help for any script (lists all its options):

    python scripts/table2_vl.py --help


1. CHECKS (seconds each)
------------------------
    python tests/test_io.py              # .es reader/writer round trip
    python tests/test_models.py          # motion models vs brute-force 3D projection
    python tests/test_chunks.py          # processing in chunks == one long run
    python tests/test_sampling.py        # event sampling + reduced camera (Table 6)

    python scripts/check_data.py         # are all dataset files there and readable?
    python scripts/check_data.py --mvsec ''     # VL only
    python scripts/check_data.py --vl ''        # MVSEC only


2. TABLE 2: TTC / divergence on VL (Ventral Landing)
----------------------------------------------------
Prints our error next to the paper's for each of the 8 sequences, plus µs/event.

    # one row (~1 min)  <-- best for a demo
    python scripts/table2_vl.py --data ../datasets/VL --model translation -s 2

    # other rows: --model scaling | translation | six_dof,  -s 2 | 3
    python scripts/table2_vl.py --data ../datasets/VL --model scaling -s 2
    python scripts/table2_vl.py --data ../datasets/VL --model six_dof -s 3

    # all 6 rows (~6-8 min)
    python scripts/table2_vl.py --data ../datasets/VL --all

    # 6-DOF with the mathematically correct Jacobian instead of the official C++ one
    python scripts/table2_vl.py --data ../datasets/VL --model six_dof -s 2 --jacobian consistent

    # save results (appends to the CSV)
    python scripts/table2_vl.py --data ../datasets/VL --all --csv ../results_python_vl.csv

Sequences: indoor_flying1 | indoor_flying2 | indoor_flying3 | outdoor_day1 | all

8. NOVELTY (our addition, not in the paper): confidence + fairer TTC metrics
---------------------------------------------------------------------------
Per-event confidence from the Gauss-Newton matrix, and new metrics (sign accuracy,
log-TTC error, delta<1.25 / delta<2, danger zone). Compares "all events" with
"most confident X %" (no ground truth used to pick them).

    # VL, works without the SSD (one model ~7 min, all 3 models ~20 min)
    python scripts/novelty_mvsec.py --dataset vl --data ../datasets/VL --model translation
    python scripts/novelty_mvsec.py --dataset vl --data ../datasets/VL --seq 2D-4 --model translation   # ~1 min

    # MVSEC (needs the SSD connected)
    python scripts/novelty_mvsec.py --data ../datasets/MVSEC --seq indoor_flying1 --model translation --max-seconds 10
    python scripts/novelty_mvsec.py --data ../datasets/MVSEC --seq indoor_flying1 --model translation
    python scripts/novelty_mvsec.py --data ../datasets/MVSEC                 # 3 sequences x 3 models (long)

    # options: --danger 5 (danger zone: GT TTC <= 5 s)   --cache DIR (reuse results, re-score fast)

    # unit test for the confidence code
    python tests/test_confidence.py

10. SAVE WHAT A SCRIPT PRINTS
----------------------------
Add  | tee <file>  to any command, e.g.

    python scripts/table2_vl.py --data ../datasets/VL --model translation -s 2 | tee ../demo_table2.txt
